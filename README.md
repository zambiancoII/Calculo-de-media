 📊 Calculadora de Média Escolar em C++

Uma aplicação simples e prática desenvolvida em **C++** para calcular a média aritmética entre duas notas escolares, ideal para o acompanhamento do desempenho acadêmico.

 📌 Sobre o Projeto

Este projeto foi desenvolvido em sala de aula como parte das atividades práticas orientadas pelo **Professor Cação**. 

O objetivo principal desta atividade foi exercitar a modularização de código por meio do uso de **funções com retorno**, facilitando a organização, reutilização e a leitura lógica do programa em C++.

 ⚙️ Como Funciona

1. O usuário insere a **primeira nota** (`nota 1`) no terminal.
2. O usuário insere a **segunda nota** (`nota 2`) no terminal.
3. A função `calcMedia()` processa os dados utilizando a fórmula da média aritmética:
   Média = (Nota 1 + Nota 2)/2

4. O programa exibe o resultado final da média na tela.

 🛠️ Tecnologias Utilizadas

* **Linguagem:** C++
* **Biblioteca Padrão:** `<iostream>`

 🚀 Como Executar o Projeto

Acesse a pasta do projeto:
cd seu-repositorio

Compile o código fonte:
g++ main.cpp -o media

Execute o programa:

No Linux / macOS:
./media

No Windows:
media.exe
